# ตำบลที่เดินอยู่ — เกมวางแผนสุขภาพพื้นที่

เกมวางแผนสุขภาพระดับตำบล เล่นจบใน 1 ปีงบประมาณ (52 สัปดาห์)
ผู้เล่นเป็นทีมสุขภาพพื้นที่ที่มีงบและกำลังคนจำกัด — **สั่งประชาชนไม่ได้ ทำได้แค่ส่งแรงลงหมู่บ้าน แล้วดูว่าคนขยับไปทางไหน**

▶️ **เล่นเลย:** https://nrok47.github.io/tambon-health-game/

---

## ⚠️ อ่านก่อนเล่น

**นี่คือของทดลอง ไม่ใช่เครื่องมือพยากรณ์**
ชื่อหมู่บ้าน ตัวเลขประชากร และสูตรคำนวณทั้งหมดเป็นค่า **สมมุติ (SYNTHETIC)** ที่สร้างขึ้นเพื่อทดสอบกลไกเกม
ไม่ได้มาจากฐานข้อมูลสุขภาพใด ไม่ใช่ผลงานวิจัย และ **ห้ามใช้ประกอบการตัดสินใจจัดสรรทรัพยากรจริง**

---

## วิธีเล่น

เริ่มเกมระบบดูแลแค่ **หมู่บ้านเดียว** จาก 26 หมู่บ้าน (ประชากรรวมสมมุติ 2,092 คน)
อีก 25 หมู่บ้านมีคนอยู่จริง แต่ระบบยังมองไม่เห็น — ต้องสำรวจขึ้นทะเบียนทีละขั้น

| ปุ่ม | ทำอะไร |
|---|---|
| **Space** | เดินเวลา / หยุด |
| **×1 ×2 ×4** หรือ `+` `-` | เร่งเวลา |
| **1-3** | เลือกมาตรการ แล้วแตะหมู่บ้าน |
| **4-6** | สร้างสิ่งปลูกสร้างถาวรในหมู่บ้าน |
| **7-8** | สร้างบนที่ว่าง (ศูนย์สุขภาพชุมชน / ถนน) |
| **R** | จอพัฒนาระบบ (สายวิจัย 3 สาย) |
| **Esc** | ยกเลิกการเลือก |

แตะหมู่บ้านบนแผนที่เพื่อดูบริบทและองค์ประกอบประชากร · หมู่บ้านที่มี**ขอบเขียวกะพริบ**คือหมู่บ้านที่ขยายเขตดูแลไปถึงได้

### สิ่งที่ต้องชั่งน้ำหนัก

- **งบมาเป็นงวด** ทุก 13 สัปดาห์ · **กำลังคนถูกจอง**ไว้จนมาตรการครบกำหนด
- **ความตื่นตัวเป็นดาบสองคม** — ตื่นตัวขึ้นคนมาตรวจเอง แต่ถ้าดันแรงเกินไปคนจะตื่นตระหนกและเลิกเชื่อเจ้าหน้าที่
- **หมู่บ้านไกลบริการตามคนได้ยากกว่า** — ได้ตรวจยากกว่า เข้าระบบยากกว่า และหลุดง่ายกว่า
- **ตรวจราชการ 3 รอบ** มาตามปฏิทิน ไม่ผ่านแล้วงบงวดหน้าถูกหั่น
- **ข่าวลวงแพร่เร็วกว่าในหมู่บ้านที่มีร้านชำและกลุ่มไลน์**

จบปีได้เกรด A–F จาก: ความครอบคลุม · คนที่อยู่ในระบบติดตาม · ไม่ปล่อยให้ป่วยเพิ่ม · ผ่านรอบตรวจ

## การ์ดเหตุการณ์

เหตุการณ์ 8 แบบเด้งขึ้นมาระหว่างเล่น แต่ละใบบอกครบว่า **ผลกระทบ / เสียหายเพิ่มเมื่อไร / ป้องกันได้ยังไง** และปิดท้ายด้วย **เกร็ดความรู้** ที่ใช้ได้จริง เช่น

> มะนาวโซดาไม่ได้ทำให้เลือดเป็นด่างและไม่รักษามะเร็ง ร่างกายคุม pH เลือดเองอยู่แล้วที่ 7.35–7.45 · การหยุดยาเบาหวาน/ความดันเองอันตรายกว่าตัวโรค

> ยาความดัน/เบาหวานตามแพทย์สั่งเป็นตัว**ชะลอ**ไตเสื่อม ไม่ใช่ตัวทำลายไต · สิ่งที่ทำลายไตจริงคือความดันและน้ำตาลที่คุมไม่ได้

## แก้ไขต่อเอง

```
index.html
css/game.css
js/config.js   ← ตัวเลข สูตร มาตรการ สิ่งปลูกสร้าง สายวิจัย การ์ดเหตุการณ์ หมู่บ้าน ทั้งหมดอยู่ที่นี่
js/sim.js      ← เครื่องคำนวณ ไม่มีโค้ดหน้าจอปน
js/ui.js       ← หน้าจอ ไม่มีสูตรปน
assets/        ภาพ pixel + ใบอนุญาต
```

**ปรับสมดุลเกม = แก้ `js/config.js` ไฟล์เดียว** · **เปลี่ยนภาพ = แก้ตาราง `SPRITE` ใน `js/ui.js` ที่เดียว**

ไม่ใช้ไลบรารีภายนอก ไม่มี build step — เปิด `index.html` ได้เลย
การสุ่มทั้งหมดผูกกับ seed (ใส่เลขเดิมได้ผลเดิมทุกครั้ง) จึงเล่นซ้ำเพื่อเทียบแผนได้
